Sample file bodies for checkAdr.test.ts, one per `== name` heading.

They live out here, in a `.txt`, for one reason: proving the checker rejects a
bad ADR reference means writing bad ADR references down, and every extension
the checker reads would make these count as the real thing. Keeping them in a
file it does not read costs one level of indirection and buys an exemption
list with nothing on it — no file gets to opt out of the rule, so no file can
quietly stop being checked.

That does couple this file to `SEARCH_EXTENSIONS` in scripts/check-adr.js: add
".txt" there and these samples light up as violations. The failure is loud and
lands here, which is the right place for it.
